# 平板界面与主题实现

主要设备为 MatePad 11 横屏，2560 × 1600、密度 400。配色与控件参考 Mediora 当前的 frontend-visual-style.md、design-tokens.css、shared-ui.css、LightRays 与 Meteors；Mediora 仓库只读。

## 最新界面要求

- 卡片的宽高、权重、间距和横向布局保持既有数值：首页内容区最小高 400dp，上排与下排入口权重 1.45:1，三路监控选择仍横向平铺，平板源卡最小高 316dp。仅放大卡内图标和文案。
- 纸白工作区、Ink #262626、Rule #E5E5E5。全部普通卡片和操作按钮按用户要求使用默认 2dp、按下 1dp 硬阴影，没有 hover。控件 4dp、卡片 8dp、工作区 20dp 圆角。
- 常规正文 16sp、辅助文字 14sp、卡片与分组标题 20sp、页标题 32sp。平板时钟 88sp、日期 32sp，均加粗；时钟下方加主题色短线。字体放大时允许滚动、表单改为单列。
- 非按钮图标采用圆润双色填面：卡片与监控入口 48dp，分组标签 24dp。按钮图标保留原尺寸，来电操作 48dp。紧凑返回与编辑图标沿用圆头线形。
- 三处网络状态是 32dp 的纯状态图标，没有外框、点击、焦点或操作暗示；辅助功能名称仅描述当前连接状态。
- 首页米家主卡使用当前主色，随主题同步切换，配低对比圆弧装饰；监控位于同排右侧。首页背景原生绘制七束错相光束和九颗稀疏流星，离开首页、失焦、后台或系统禁用动画时停止持续刷新。原黑金主卡已被当前要求替代。

## 全局主题

配色和名称直接对应 Mediora：青绿 #A3E635、翡翠 #7EE2B8、墨黑 #303030、蓝色 #A0BCFA、蔚蓝 #1269E8、紫色 #C4B1F5、玫瑰 #F3A7CA、琥珀 #F2CA71、珊瑚 #F2AA91。墨黑和蔚蓝主色表面使用白色前景，其余使用 Ink。

外观分组展示九种配色，点击即本地保存并全局应用；Android 通过主题 overlay 与可解析主题属性的共享颜色资源实现。主色影响主卡、主按钮、选中态、背景装饰；辅助表面为主色 4% 混白，选择表面为 18% 混白，外壳为 2.5% 主色混 #F7F7F5。成功、运行、失败、连接状态保持固定语义色。

外观配置使用独立 appearance 偏好文件，不改变本户身份、网口或门机字段。切换后重建界面并恢复当前设置分组，重启后仍保留主题。未知旧主题标识回退为默认色。本地设置采用即时生效，不搬入 Mediora 服务端账户权限和保存流程。

## 设置与通话

设置分为本机与网络、门机设备、声音与通话、外观。表单标签在上，数值与编辑操作在下，横屏两列，窄窗口或大字体单列。五个本机字段和七个门机字段均可编辑，校验、保存、取消和重建草稿保留；连接方式仍由页头按钮打开弹窗。

开关使用 32×20dp 轨道与 16dp 滑块，支持点击、焦点、checked 与持久化。音量按系统真实范围调整。来电保持左视频、右侧两个正方形操作；开锁后自动挂断仅在成功发送请求后计时 3 秒，关闭时手动挂断。真实来电、双向声音和物理开锁仍按用户安排留待现场验收。

## 验证

- 协议、配置和外观标识单元测试，Python 抓包工具回归，两种构建与 Lint。
- 同一个原生 GridLayout 实例连续九次跨分栏阈值，验证双列与单列相互切换。
- 目标平板尺寸下检查图标、文字、阴影、卡片尺寸、四个设置分组、九种主色、深色前景对比、重启持久化、动效停止。
- 离线样本验证来电正方形按钮、接听/挂断、3 秒自动挂断与手动模式；真机只检查界面与配置，不发送实际开锁或呼梯。

## 本地验收结果

56 项 JVM 测试、9 项 Python 测试通过；Debug/Release Lint 均为零问题，两种构建成功，发布 APK 签名校验通过且仅包含图标授权文本，没有监控抓包资源。

拆分米家入口前，平板模拟器逐项切换全部九种主题，主页主卡像素颜色与对应 Mediora 原色一致；当时三张首页卡片的宽高在九次重建后完全相同。主题强停重启仍保留；放大字体、竖屏单列与外观标签位置恢复通过。原生布局探针验证同一 GridLayout 连续九次跨越分栏阈值、图标禁用/忙态/启用三种组合与网络图标不可交互。

动效测试在首页观察到持续绘制，设置页和系统关闭动画后均为零持续帧。离线来电确认两个方形按钮、增大的操作文字、接听及挂断；3 秒自动挂断和关闭后的手动模式已回归。真实来电和物理开锁没有在本轮触发。

该阶段版本经华为帐号验证后已安装到 MatePad 11，并核对设备安装包与本地构建的 SHA-256 完全一致。真机检查了四个设置分组、本机字段、不可交互的网络状态、自动挂断开关触屏切换与恢复；全局主题切换后的主卡像素符合目标色，当时三张首页卡片尺寸不变。测试后恢复原主题、开关和 30 秒亮屏时间，本户配置及运行模式与更新前指纹一致。

## 首页入口与展示调整

按最新要求，将原大监控卡在原区域横向拆为两块：左侧主色米家、右侧监控；下方电梯和设置保留，整行高度和外围卡片布局不扩大。米家入口使用已安装 App 的图标与标准启动入口，Android 11+ 仅查询对应包；未安装或入口不可用时提供文字提示。跨 App 后返回沿用现有前台恢复连接逻辑，后台来电接收仍属后续范围。

卡片图标由 32dp 增至 48dp，二级监控入口同步放大；星期与日期统一 32sp 加粗。普通设置数值改成无背景纯文字，点击编辑后才显示输入框。光束透明度由 0.16 增至 0.22，墨黑主题 0.045 增至 0.06；流星强度相应小幅提升，动效停止规则不变。

本轮验证：56 项 JVM、9 项 Python 测试通过，Debug/Release Lint 均为零问题，两种构建及签名校验通过。已安装到 MatePad 11，真机核对四入口位置、48dp 图标、三路门机选择、无框数值与编辑弹窗。点击米家入口后确认米家进入前台，返回本 App 正常；原有配置文件指纹及亮屏时间均已保持/恢复。未触发实际呼梯或开锁。
