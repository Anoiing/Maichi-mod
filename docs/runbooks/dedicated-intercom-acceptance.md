# 专用门禁终端验收记录

本记录区分本地自动测试、隔离模拟器与真实门禁现场结果。未执行不等于通过。禁止用自动测试触发真实开锁或呼梯。

## 环境与阶段

- 开发基线：`c65ddbe`；方案基线：`547d807`。
- 本地：JDK 17，Android target 36，离线回放使用本机私有样本。
- 隔离模拟器：API 36，独立任务/配置测试，不连接真实门机。
- 现场平板：DBY-W09 / API 31；2026-11-13 只读检查时 USB 供电、电量 100%。此读数不证明网口与持续供电同时可用。
- 现场真实来电、双向声音、物理门锁、电梯、网络拔插、重启和闲置返回尚未执行。
- 24 小时 / 72 小时观察尚未开始；第一期现场验收通过之前不接入相机感知。

## 执行规则

每次记录构建提交、设备/API、步骤、预期、实际、时间和必要证据。模拟器不验证厂商保活/锁屏限制或物理设备效果。系统授权/系统设置由现场人员参与；强行停止后需手动打开应用，这是系统行为。

失败先修复并重跑相关路径，再进入下一阶段。任何配置、主题、页面或自动返回的变化，都要核对没有额外创建/关闭监听 Socket。
