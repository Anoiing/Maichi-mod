## 缺陷、定位与修正

### 分隔线留白

真机复现正文和分组标题紧贴分隔线。共享 `SettingsDivider` 原来没有上下 margin，各页页头后的留白也由调用方分别提供。按当前适配规范统一：分组分隔线上下各 24dp，页头线下 16dp，相关控件 8dp，设置标签底部 12dp；网格末行不叠加行距。三路源卡复用同一分隔线。弹窗正文 16dp 线下及横向 24dp 留白保留，既有大屏字号、卡片比例、主题和硬阴影沿用。

### 普通参数被误标密码

原 `SettingInput` 的 `textVisiblePassword` 使华为 `input_method_secure` 实际激活安全键盘，截图返回 0 字节；只看普通输入服务会误判为键盘隐藏。房号/IP/MAC 非密码，最终包改为 `text|textNoSuggestions`，保留单行、禁止自动填充及校验，时长仍显式数字输入。此前空截图未计为视觉通过；隔离设备竖屏大字体有实际像素证据，最终包真机亦已完成上述普通键盘和竖屏大字体复测。

### 后台来电未自动展示

留白版在真实米家前台和息屏时均未自动显示。原服务只发布全屏通知；Android 对已解锁设备的全屏通知可能仅展示横幅，不能据通知已发布推断来电页已显示。[Android Notification.Builder 文档](https://developer.android.com/reference/android/app/Notification.Builder#setFullScreenIntent(android.app.PendingIntent,%20boolean))

原外部应用用例人工发送通知 Intent，只证明通知入口和返回原任务，未证明自动展示。移除人工启动后先失败于 `call activity did not appear`，再由服务为每个有效响铃键请求一次既有独立来电任务，系统权限和后台启动限制仍生效，通知继续保留。复审另确认缓存授权不能代表当前系统设置：通过真实系统频道开关先复现关闭后仍弹出，再使通知和直接启动共用同一次实时权限检查。两项关键用例均已转为通过。最终包真机仍首次失败，实时日志确认来电已触发、通知携带全屏 Intent，但华为以 `Background activity start` / `hwInterceptionMask=6160` 拦截直接启动；通知声明频道等级为 4，实际生效等级为 3。未将隔离验证冒充真机通过。

随后检查系统「应用信息 → 其他权限 → 后台弹窗」，实际选中“禁止”，但 `dumpsys package` 的华为虚拟权限同时显示 `granted=true`。已仅对此门禁应用在系统页面选择“允许”；随后真实米家前台与息屏各自等待 15 秒后的自动来电展示均通过。这是当前设备明确的配置前提，不凭普通权限查询判断厂商开关，也不更改其他应用或全局限制。[华为后台弹窗权限说明](https://consumer.huawei.com/cn/support/content/zh-cn15999149/)

### 强停后的操作检测授权

当前华为系统的“强行停止”会从已启用列表移除操作检测，显式打开只恢复接待。设置正确提示“系统操作检测未运行”，未把保存的开启意图当作实际运行。测试后已通过正常系统界面重新开启此前用户授权的同一服务，保留 SmartFace；随后以实际绑定状态核对恢复，不只看开关。以后若强停，闲置返回需重新开启检测服务。

### 验证方法校正

完整回归暴露了旧系统菜单检查依赖第二次 `RESUMED` 事件的问题。两系统诊断均记录：收起菜单前来电页已经 `RESUMED`，但 `focus=false`；收起后只改变窗口焦点。现允许复用既有页面，同时额外要求菜单收起后两秒内获得实际窗口焦点，保留总时限。锁屏检查改为至多等待两秒，确认系统实际进入 `isInteractive=true`，没有以生命周期代替亮屏。此修订仅修改设备测试，最终安装包的 SHA-256 不变。API 36 两项复测通过；API 31 并发冷加载实际达到 62,062ms，超出既有 40 秒就绪前提，该次不计功能结果，释放另一台隔离设备资源后单独复测，两项均通过，耗时 12.651 秒，保留原等待上限。因此两系统各 69 个用例均已有通过证据；完整初跑和追加复测分别记录，未将初跑失败抹去。

主题测试起初误取 Service 列表第一项，实际取到会随 UI 自动化重新绑定的操作检测服务；改为精确匹配 `.IntercomService` 后九主题连续性通过。闲置倒计时期间不使用会干扰无障碍服务的 UI 自动化连接。收尾再次确认该连接可能使检测服务保留开启标记但被系统列为未绑定/已中断；最终重新绑定后停止连接 UI 自动化，改用系统绑定状态与直接像素截图核对，不能只凭授权显示为已开启就报告运行。地库 2 短样本自然结束曾与手动返回重叠，已另行在播放早期验证退出正常，不计为产品缺陷。
